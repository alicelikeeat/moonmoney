# Bundled font licenses

All fonts live in `MoonMoney/Resources/` and are used only by the pixel skin.
Each license text ships inside the app (我的 → 开源许可) and next to the font.

| File | Font | License | Notes |
|---|---|---|---|
| `ArkPixel12.otf` | Ark Pixel Font 12px Proportional zh_hans, © 2021 TakWolf | SIL OFL 1.1 (`OFL-ArkPixel.txt`) | Subset to GB2312 + Latin + symbols |
| `FusionPixel8.otf` | Fusion Pixel Font 8px Proportional zh_hans, © 2022 TakWolf | SIL OFL 1.1 (`OFL-FusionPixel.txt`, includes the licenses of its component fonts) | Subset as above |
| `MoonPixelCJK.otf` | Renamed subset of GNU Unifont 15.1.01 | SIL OFL 1.1 option of Unifont's dual license (`OFL-Unifont.txt`) | Subset as above |
| `PressStart2P-Regular.ttf` | Press Start 2P, © 2012 The Press Start 2P Project Authors | SIL OFL 1.1, Reserved Font Name "Press Start 2P" (`OFL-PressStart2P.txt`) | Unmodified |
| `Silkscreen-Regular.ttf` | Silkscreen, © 2001 The Silkscreen Project Authors | SIL OFL 1.1 (`OFL-Silkscreen.txt`) | Unmodified |
